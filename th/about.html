วัตถุประสงค์ของโครงการ
เว็บไซต์ septuaginta.com.br ถูกสร้างขึ้นเพื่อให้คำของพระเจ้าเข้าถึงทุกคนได้อย่างฟรี ง่าย และรวดเร็ว

การเข้าถึงแบบฟรีและเปิดเผย
เนื้อหาพระคัมภีร์ทั้งหมดสามารถอ่าน ค้นหา และแบ่งปันได้อย่างอิสระ ไม่มีโฆษณา ไม่มีการเก็บข้อมูล และไม่จำเป็นต้องลงทะเบียน

การใช้เทคโนโลยี
พัฒนาโดยใช้ HTML, CSS และ JavaScript ล้วน ๆ โครงการนี้ถูกออกแบบให้มีประสิทธิภาพเบา และเข้ากันได้ดีกับทั้งอุปกรณ์มือถือและคอมพิวเตอร์

ความมุ่งมั่น
เราไม่ได้แสวงหากำไร เพียงต้องการเผยแพร่พระคัมภีร์ หากคุณพบข้อผิดพลาดหรือประสงค์จะช่วยปรับปรุง สามารถติดต่อเราได้
