Objetivo del Proyecto

El sitio web septuaginta.com.br fue creado con el propósito de hacer que la Palabra de Dios sea accesible para todos, de forma gratuita, sencilla y rápida.

Acceso Libre y Abierto

Todo el contenido bíblico puede ser leído, buscado y compartido libremente, sin anuncios, sin recopilación de datos y sin necesidad de registrarse.

Uso Tecnológico

Desarrollado utilizando HTML, CSS y JavaScript puros, el proyecto fue diseñado para un rendimiento ligero y una excelente compatibilidad tanto con dispositivos móviles como con computadoras.

Compromiso

No buscamos lucro, solo compartir las Escrituras. Si encuentra errores o desea contribuir con mejoras, siéntase libre de ponerse en contacto.
